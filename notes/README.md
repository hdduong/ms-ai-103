Read each module in unit order. The lessons combine the Microsoft Learn concepts with the relevant exercise code or portal steps: what the example does, how the important lines work, and what result to check. There are no separate exercise pages.

The tables in each path README link directly to these worked examples. Where an example spans lessons, follow its setup and continuation links; a code block labeled as a replacement belongs in the named file or function. Portal-only exercises use configuration, prompts, and observed results instead of an invented Python implementation. Sources are linked beside the examples, with licenses in [third-party notices](../THIRD_PARTY_NOTICES.md).

- [AI-103 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-103): check the exam objectives.
- The two paths do not fully cover computer vision, text and speech analysis, or information extraction (OCR, Content Understanding). Study those separately.

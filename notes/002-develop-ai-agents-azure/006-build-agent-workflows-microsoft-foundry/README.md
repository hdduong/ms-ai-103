# 006 Build agent-driven workflows using Microsoft Foundry

[build-agent-workflows-microsoft-foundry](https://learn.microsoft.com/en-us/training/modules/build-agent-workflows-microsoft-foundry/)

The [current migration guide](https://learn.microsoft.com/en-us/azure/foundry/agents/concepts/workflow#migration-guide) says the **visual designer and in-portal execution** are unsupported after **December 1, 2026**. Export existing workflow YAML before then. YAML definitions can continue to run when deployed as hosted agents; Microsoft Agent Framework supports the recommended YAML or code migration path, and Azure Logic Apps is a visual alternative. This does not retire every workflow definition or every Agent Framework workflow.

Reviewed **2026-11-07**. The [exercise lesson](09-exercise.md) includes official lab code, dependencies, setup, and source provenance.

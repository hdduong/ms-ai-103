# 007 Build agent-driven workflows using Microsoft Foundry

[build-agent-workflows-microsoft-foundry](https://learn.microsoft.com/en-us/training/modules/build-agent-workflows-microsoft-foundry/)

The Foundry portal says workflows retire on December 1, 2026: the designer and in-portal runs stop, and exported YAML still runs as a hosted agent. New workflows should use Microsoft Agent Framework (modules 008 and 009). See the [migration guide](https://learn.microsoft.com/azure/foundry/agents/concepts/workflow#migration-guide).

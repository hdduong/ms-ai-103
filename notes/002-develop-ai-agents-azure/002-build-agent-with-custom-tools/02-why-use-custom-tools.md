# 02 Why use custom tools

[Why use custom tools](https://learn.microsoft.com/en-us/training/modules/build-agent-with-custom-tools/2-why-use-custom-tools?pivots=text)

- Built-in tools stop at the catalog. A custom tool reaches your CRM, inventory, schedule, tickets, or LMS.
- The agent decides whether to call it. You do not hard-code the call in the prompt handler.
- Typical path: user asks, agent picks the tool, tool returns data, agent answers.
- Payoff is less repeated work and the same answer every time, because the tool hits the system of record.
